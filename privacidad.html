Política de privacidad: Cuadratura de facturas (prototipo)

Última actualización: 25 de noviembre de 2026.

1. Quién es el responsable

El responsable del prototipo es su autor, identificado en el repositorio github.com/alcides-nolasco. Para consultas, abra una incidencia en este repositorio.

2. Qué hace la aplicación

La aplicación lee un buzón de correo electrónico de prueba, compara las facturas electrónicas que llegan en ese buzón contra la orden de compra correspondiente y responde al remitente con el resultado.

3. Datos que trata

  • Correos del buzón de prueba: dirección del remitente, direcciones en copia, asunto, texto y archivos adjuntos.
  • Archivos adjuntos: facturas electrónicas en JSON y PDF, y órdenes de compra en PDF. Pueden contener nombres de empresas, direcciones, números de identificación fiscal y montos.
  • Datos técnicos: identificadores de los correos, resultados de la comparación y registros de errores.

La aplicación no pide datos a personas que no envían correos al buzón de prueba, no usa cookies de seguimiento y no tiene publicidad.

4. Para qué se usan los datos

Solo para comparar las facturas con la orden de compra, responder al remitente, dejar constancia de cada decisión y registrar el costo de los servicios de procesamiento. No se usan para publicidad, no se venden ni se ceden a terceros con fines comerciales.

5. Proveedores que procesan los datos

  • Google Cloud: aloja la aplicación (Cloud Run), la base de datos (Cloud SQL, región us-central1) y los secretos de acceso.
  • Gmail (API de Google): lectura del buzón de prueba y envío de las respuestas.
  • TypeSafe (Jev AI): recibe descripciones de productos y líneas de factura para compararlas con la orden de compra.
  • Anthropic (Claude) y Google (Gemini): reciben fragmentos de las facturas cuando la comparación automática no basta, para sugerir equivalencias. Se envían solo los datos necesarios para esa comparación.

6. Conservación

Los datos se conservan mientras dure la prueba. El periodo de conservación no está definido todavía y se publicará aquí antes de cualquier uso fuera de la prueba.

7. Uso de datos de las API de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La aplicación solo solicita el acceso a Gmail necesario para leer el buzón de prueba y enviar las respuestas.

8. Sus derechos

Quien haya enviado un correo al buzón de prueba puede pedir la supresión de sus datos abriendo una incidencia en el repositorio indicado en el punto 1.

9. Cambios

Esta política puede cambiar. La fecha de la última actualización aparece arriba.
